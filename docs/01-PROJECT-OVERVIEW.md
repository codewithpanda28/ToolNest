# ToolNest — Project Overview

## Goal
Build a directory website where users can discover and submit businesses and tools.

## Core Features
- Homepage shows top businesses + top tools (leaderboard preview)
- `/businesses` page: full business directory + leaderboard
- `/tools` page: full tools directory + leaderboard
- Users can submit their business/tool
- Paid leaderboard: pay more than current #1 to rank up
- AdSense approval ready (legal pages, blog, SEO)
